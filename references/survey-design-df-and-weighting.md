## 一、自由度：设计 df 与检验 df 是两层，不能混

### 1.1 三个数各自是什么

| 量 | R 里怎么取 | 含义 | 实测（本课题） |
|---|---|---|---|
| **设计自由度** | `survey::degf(design)`（= `svydesign` 对象上的自由度）| `Σ(m_h − 1) = #PSU − #层`。**只由抽样设计决定**，与模型、与是否含交互项**无关** | P 25 / L 15 / N3 49 / 合并 89 / P-vs-L 40 |
| **模型残差自由度** | `fit$df.residual`（`svyglm` 对象）| `degf(design) − (rank(model.matrix) − 1)`，即**估完参数后剩的设计信息** | 合并总关联 79、合并 M4 77、P-vs-L 32；P M3/M4 = 11/9；L = 1/**−1**；N3 = 36/34 |
| **检验分母自由度** | `regTermTest(fit, ...)$ddf` | 默认（`df = NULL`）**就等于上面那个残差自由度**；显式传 `df =` 才改 | 与残差 df 逐一吻合（9 个模型全部验过）|

⇒ **89 与 79/77 可以同时成立**：前者是设计层，后者是模型层。审稿人不会因为数值不同判错，
**但会因为"前文说用 89、后文写 79/77 却没解释"而判解释不准确**。

### 1.2 解释必须落到 rank 上，不能笼统说"交互项消耗自由度"

实测反例：总关联交互模型与 M4 交互模型的**交互项完全相同**，但 ddf 是 79 vs 77。
差别来自 M4 **多估了 age、BMI 两个主效应**（模型矩阵秩 11 → 13），不是交互项。

标准写法（可直接改用）：

> `degf(design) = Σ(m_h − 1) = #PSU − #strata` is a property of the sampling design alone.
> `regTermTest` with its default `df = NULL` uses the **model residual degrees of freedom**,
> `df.residual = degf(design) − (rank(model matrix) − 1)`. The pooled interaction model and the
> pooled M4 model therefore differ (79 vs 77) because M4 estimates two additional main effects
> (age and BMI; rank 11 → 13), not because the interaction terms consume degrees of freedom.

### 1.3 负的残差自由度：如实报告，**不要**外推成"模型超出可用信息"（v17 被审稿人纠正）

实测：**L 层 M4 的 `df.residual = −1`** —— 17 个参数，而该层只有 **15 个设计自由度**。

⚠️ **上一版这里写错了**（写成了"这说明该层 M4 超出了可用的设计信息"）。审稿人（GPT6）在 v17 轮
明确指出这是**过度外推**，原话：

> 「**默认残差自由度为负，并不自动意味着这 17 个回归参数无法估计，也不能单凭这一点证明过拟合。**
> 需要区分**参数估计、协方差估计和检验参考分布**三件事。」
> 「survey 官方文档明确**允许**使用 `df.resid = degf(design)`，同时指出默认减去模型参数的方式，
> 对个体层面的协变量可能**很保守**。」

- ✗ 不要写：`the model exceeds the available design information` /
  "17 个参数超过 15 个自由度，所以模型超出可用信息"。
  负残差 df **只说明默认检验参考分布的选择问题**，不说明参数不可估、也不证明过拟合。
- ✓ 正确写法（三段，可直接改用）：
  1. **如实报告**：`df.residual = −1`（17 参数 / 15 设计自由度），原样报数、**不作分母**；
  2. **说明推断设置**：各周期单系数推断**统一采用设计自由度**（`df.resid = degf(design)`），
     因为对个体层协变量，默认"减去模型参数"的做法偏保守；
  3. **保留谨慎提醒**：该层 PSU 数有限，临界显著结果（如 L 层 M4 的 P≈0.04）需谨慎解释。
- ⇒ 读者按默认设置复现不出同样的 P，所以**必须**写明用的是哪个 df；但**理由要落在"推断设置的
  选择"上，而不是"模型失效"上**。
- 通用判据：`rank(model.matrix) − 1 > degf(design)` 的层/模型，其 P 与 CI 标注
  "computed with `df` set explicitly to the design degrees of freedom"，并把 −1 如实留在核对表里。
- 心态提醒：审稿人原话「**我没有据此认定 P=0.048 算错。需要修正的是理由，不能把合理的推断设置
  写成临时挽救一个无效模型。**」

### 1.4 审稿人要什么（表格式交代）

一张补充表，逐模型给：**模型公式 | `rank(model.matrix)` | `degf(design)` | `fit$df.residual`
| `regTermTest` 的 df/ddf | 是否显式设 `df`**。
这张表本身就是"我们知道自己报的是哪个自由度"的证据，能一次性关掉这类追问。

### 1.5 不要为了"数字统一"而机械地让所有检验共用一个自由度

同一个 §2.6 里同时出现设计 df 与检验 df 是**正确**的；错的是**不说明**。
统一成一个数反而会掩盖 1.3 那类问题。

### 1.6 「先子集再建 design」vs「先建 design 再 subset」——CDC 警告与本包实测

CDC 方差估计教程的原话是 **never delete or drop records before executing analysis
procedures**，并解释：先把数据集裁到子人群，方差公式会把**子群样本量当作固定值** →
**低估方差**。审稿人据此要求核查建模顺序（本条即由此而来）。

**实测结论（本包 survey 4.5，非校准/非 PPS 设计）：两者结果完全相同。**
P/L/N3 × M1–M4 共 **12 个模型**，OR、SE、95%CI、P、degf 的差 **全部为 0**
（`|ΔOR| = |ΔSE| = 0`，仅浮点误差量级）。

原因：`subset.survey.design` → `[.survey.design2` 走的是**精确行子集化**分支，
逐行裁剪、不保留被排除记录，因此与"先筛选再建 `svydesign`"得到**同一个 design**；
且本例分析样本未使任何层内 PSU 数降到 1（**无 lonely PSU**）。

⇒ 可操作结论：
- **不必推翻已有结果**，但**必须在方法里写明已按 CDC 建议核验过**——这句话本身就是
  「我们知道自己用的是哪个 design」的证据，能一次性关掉这类追问。
- 报告子群**实际保留的 strata / PSU / degf**（本例 P 24/49/25、L 15/30/15、N3 49/98/49）。
- **但不要把它当成普适真理**：换成**校准（calibrated）或 PPS** 设计，或子集后出现
  lonely PSU，两者就会分叉。写进稿件时限定为"本分析的设计类型下等价"。
- 若真出现分叉，才改用 design-first + `subset(des, condition)` 重跑，并以新结果为准。

可复用探针：
```r
# 两法对比：任取一个层×模型，比 OR/SE/degf
f1 <- svyglm(f, subset(des_full, inA == TRUE), family = quasibinomial())  # design-first
f2 <- svyglm(f, svydesign(ids=~psu, strata=~stra, weights=~w,
                          data = sample_d[d$inA, ], nest = TRUE), ...)     # subset-first
cat(abs(coef(f1)["x"] - coef(f2)["x"]) < 1e-12,   # TRUE = 等价
    degf(f1$design) == degf(f2$design))
# 子集内 PSU 数是否 >= 2 per stratum（制造 lonely PSU 才会分叉）
table(table(sample_d$stra[sample_d$inA]))

## 二、选择加权（IPW）：先锁定"加权代表谁"，再谈效果

### 2.1 目标人群的选择会决定分析是否成立（本课题最重的一条）

两种候选：

- **T1 = 全部合格晨间空腹样本**
- **T2 = 指数可计算人群**（本例 = 七组分均可测、GLM7 按既定公式有定义）

实测后果：**若按 T1 建模，结构性不可计算者的选择概率 p̂ ≈ 0 → 近乎完全分离**：
`1/p̂` 极大（N3 达 `4.2e5`）、**有效样本量 ESS 由 2,363 塌缩到 340**、
M3 的 ΔOR 竟变成 **−0.19**（符号翻转）。按 T2 建模则一切稳定。

⚠️ **但不要说"因为 ESS 会塌缩，所以不能外推到 TG≥400 者"** —— 审稿人在 v17 轮指出这个推导**不成立**：

> 「§3.9 还把高 TG 排除者的预测概率接近零，直接解释为分析样本 ESS 必然崩塌。**这一推导不成立：
> 从未入组者不会直接进入最终加权估计；ESS 是否下降，要看实际入组者获得的权重。**
> 不能外推到该人群的理由，是**既定 Friedewald 实现下缺乏可计算暴露及相应支持**，而不是 ESS 必然下降。」

- ✓ 正确的论证方向：**支持域（support）问题** —— 目标公式在该人群上无定义（LDL 不可算），
  因此**没有可外推的暴露量**，与权重大小无关。
- ✓ ESS 的数字（2,363 → 340）只作为**"T1 口径下模型退化"的实证症状**来报，不要写成机制解释。

### 2.1b 三个人数必须分开报（v17 被审稿人抓）

**最容易犯的错**：选择模型内部一句 `complete.cases(...)` 把缺失预测变量的人**再次删掉**，
于是"目标人群"与"实际建模人群"悄悄不是同一批人，而正文仍按目标人群的人数描述选择过程。

实测（本课题 v16 → v17）：选择模型含 `PIR`，且 `complete.cases` 里也含 `pirf`
→ NHANES III 的建模框从 **6,713 缩到 6,045**，而正文仍把目标规模写作 6,713。
审稿人一眼看出：**"这 661 人因 PIR 缺失被排除（Figure 1），他们怎么进入含 PIR 的选择模型？"**

⇒ **必须报三个数**（一张小表）：

| 层 | 目标人群 n | 进入选择模型 n | 因预测变量缺失再删 | 最终分析 n |
|---|---|---|---|---|
| P | 3,628 | 3,146 | 0 | 2,885 |
| L | 2,750 | 2,413 | 0 | 2,092 |
| N3 | 6,713 | **6,045** | 0 | 5,918 |

- 两个可选口径，**选一个写明**，另一个作敏感性：
  - **(a) 目标限定为"预测变量可得"者**（n_target = n_model，口径自洽，推荐）
  - **(c) 目标 = 全域，选择模型不含该变量**（本例去掉 PIR）
  - (b) 多重插补也可，但要说明为何不用（本例未用有说明）
- T2 内的 PIR 缺失实测：P 482 / L 337 / N3 668（13.3% / 12.3% / 10.0%）——**要报出来**，
  否则读者以为目标人群里人人都有 PIR。
- ✓ **恒等式自检**：含截距的 logistic 必有 `mean(p̂) = 入组率 (= n_analysis / n_model)`。
  实测 6 组全部吻合（差 < 1e-12）。**不吻合就说明 p̂ 与 `inA` 不是同一批人算的。**
  这条恒等式还能一次性挡掉"你报的 p̂ 范围与入组率矛盾"这类质疑
  （本例 5,918/6,662 ≈ 0.888 vs 报的 p̂ 范围 0.896–0.999，**分母不同**所致，不是算错）。

### 2.1c 别用"目标外人群的缺失性"解释"目标内变量的取舍"（逻辑自洽）

v16 曾写"选择模型不含 LDL，因为**被排除者中 LDL 结构性缺失**" —— 与"目标 = 指数可计算人群"
**自相矛盾**：若目标就是可计算人群，则该集合内 LDL 必然可得。

- ✓ 正确表述：目标本就是"指数可按既定公式计算者"；LDL 的结构性缺失只发生在 **TG ≥ 400 者**，
  **这些人本就在目标之外**。

⚠️ **但\"在目标内它恒可得、不具区分作用\"这句话本身也是错的**（v18 轮被审稿人纠正）。
原话：

> 「**变量均有测量值，不等于变量数值没有预测作用。** LDL 缺失指示在目标人群内可能没有变异，
> 但 **LDL 浓度仍然可能与其他变量缺失、最终入选有关**。如果实际原因是避免与其他脂质变量的
> 确定性关系、共线性或模型复杂度，应按真实理由说明。」

实测（本课题）：LDL 在目标人群内 **100% 非缺失**（结构性完整），但**并非无变异**——
SD = **0.93 / 0.95 / 0.98 mmol/L**（P/L/N3），P5–P95 约 1.4–5.0，CV 0.30–0.34。
加入选择模型后系数**弱且不显著**（OR per 1 SD = **0.94 / 0.99 / 0.93**，
P = **0.35 / 0.89 / 0.42**），伪 R² 仅由 0.0348/0.0501/0.0299 变到 0.0353/0.0502/0.0305，
IPW 的 M3/M4 OR 变化 **|ΔOR| ≤ 0.002**。

⇒ **可复用的判据：不要用\"变量完整\"论证\"变量无信息\"。** 正确写法是**按真实理由陈述**：
  1. 这是**事先的模型简约性选择**（本例：指数的七组分中已有六个在模型内，再加入 LDL
     等于把入组概率建模为**暴露完整构成**的函数，条件于暴露本身/循环）；
  2. Friedewald LDL 由 TC / TG / HDL **代数推出**，与已入模型的两个脂质变量**部分冗余**——
     **报实测相关系数**（本例仅 **r = 0.10–0.22，中等**），不要夸大成\"高共线\"；
  3. 加上模型简约性；
  4. **把\"加入 LDL 的选择模型\"结果列为事后稳健性**（本例 |ΔOR| ≤ 0.002、系数均不显著），
     而不是当成不纳入的理由。
- 通用形态：审稿人对\"某变量没进模型\"的理由特别敏感。**任何以\"它没有用\"为由的排除都要有实测支撑；
  若排除实际来自简约性/冗余/复杂度，就直接这么说。**

⇒ **主推断必须锚定 T2**，措辞：
> the primary inference targets the adult morning fasting subsample in which all seven components
> are measurable and the index is computable by the defined formula.

### 2.2 结构性不可计算 ≠ 普通缺失（必须分开报）

- **结构性不可计算**：由公式的成立条件决定，**选择加权无法恢复**。
  本课题 = Friedewald LDL 在 **TG ≥ 400 mg/dL** 无定义（CDC 文档明确）。
  实测人数：P **32**、L **32**、N3 **165**。
- **普通缺失**：协变量/结局缺失，理论上可由重加权补偿。

审稿人会直接追问"你加权的是哪一群人"；把这两类分开列数（一张 2×3 的小表）是最省事的答法。
**并且**：不要因为队列构建阶段排除了 TG≥400 就以为分析样本里没有——
要报"分析样本内 TG 的最大值"来证明这批人是否真的都没进来（本课题 = 399，正好卡在界内）。

### 2.3 一张 IPW 交代表应含的六件要素

审稿人（GPT6）逐条问过，缺一条就被追：

1. **目标人群**（T1 还是 T2，见 2.1）
2. **选择模型的变量清单** + 形式（logistic）
   —— 本课题：`inA ~ age + age² + sex + race + BMI + FBG + insulin + TG + HDL + PIR`，
   **刻意不含 LDL**（它正是结构性缺失项）
3. **与抽样权重如何结合** —— 本课题：`w_final = 空腹抽样权重 × (1/p̂)`，
   在分析样本内归一化（均值 = 1）
4. **权重诊断**：p̂ 的范围、是否截断（阈值、受影响比例）、**加权后 ESS**
   —— 实测 p̂ 范围 P [0.684, 1.000]、L [0.528, 0.963]、N3 [0.896, 0.999]；
   P99 截断；ESS 几乎不变（P 1,287 vs 1,260；L 1,271 vs 1,289；N3 2,368 vs 2,363）
5. **加权后的 OR 与 95% CI** —— **不能只报 ΔOR**
6. **同一加权方案下是否重跑了 M4（以及判别 ΔAUC）**

### 2.4 M3 稳 ≠ M4 稳（别用主模型结论外推）

实测：加权后 **ΔOR 全部 < 0.014**（N3 M3 1.999、M4 1.244；P M3 1.645、M4 1.335；
L M3 1.415、M4 0.833），判别 ΔAUC 亦基本不变。
但审稿人明确提醒：**"M3 稳定不能自动保证 M4 或增量判别结果稳定"**——
所以要**在同一加权方案下把 M4（必要时还有主要 ΔAUC）也跑一遍**再下结论。
（不必把所有附加分析都重跑；挑审稿人会问的那几个。）

### 2.5 选择加权放在哪一节

- 方法：目标人群定义 + 结构性/普通缺失之分 + 选择模型 + 权重合成 + 诊断指标
- 结果：一张表（六要素）+ 一句结论（"加权前后各估计基本不变"）
- 局限：写明结构性不可计算者无法由加权恢复，主推断的人群边界在哪
- **不要**只在局限里报一个 ΔOR —— 那正是本课题被要求补做的原因

### 2.6 截尾：报**未截尾**为主结果，截尾作敏感性；且别把两种截尾混为一谈（v17 新增）

审稿人的两条原话：

> 「你截尾的是**最终权重 = 调查权重 × 选择概率倒数**，而不是单独的选择概率倒数。
> 这样**同时改变了原始调查权重与缺失校正权重**。」
> 「建议**先报告未截尾的 IPW 结果**，再把 99% 截尾作为敏感性分析。否则，
> 'OR 几乎没变' 可能混合了**选择校正**与**截尾**两种影响。」

- 本例选择权重其实**不极端**：`1/p̂` 最大 ≈ **P 1.46 / L 1.83 / N3 1.12**。
  ⇒ **最终权重大多半来自原有抽样设计，不该自动当成需要截尾的异常。**
- ✓ 三套并列报告：**未截尾** / 仅截尾选择权重 / 截尾最终权重。
  实测三者几乎一致（N3 M3 1.999 / 1.999 / 1.998；L M4 0.833 / 0.833 / 0.833），
  所以"结论不变"这句才站得住。
- ✓ 报"截尾影响了多少比例的权重"（本例各层 < 1%），别只说"做了截尾"。

### 2.7 IPW 的 CI 必须交代是否含选择概率的估计不确定性（v17 新增）

审稿人问：「IPW 的置信区间**是否考虑了选择概率的估计不确定性**？若采用 bootstrap，
应说明是否在**每次重复中重新拟合选择模型**；若把估计权重视为固定值，则明确这一限制。」

- 解析式（`svyglm` 三明治方差）把 p̂ 当**固定值** → **不含**该不确定性来源，**必须写明这个局限**。
- ✓ 稳妥做法：**分层整群 bootstrap（重抽 PSU），每个重复内重新拟合选择模型**再重算权重与 OR。
  实测（B=200）CI 与解析式一致，故可写"未低估"。
- 注意：PSU 数少的层（P、L）bootstrap 中位数会有偏移，如实标注即可。

### 2.8 各层"完整病例"定义必须一致，否则统一后**重算**（v17 新增）

实测事故：主关联分析中 **P 与 NHANES III 不要求腰围，L 却要求**（2,092 → 2,056，
36 人因腰围缺失被排除），而方法里又说"腰围只用于 LAP 判别比较"——**口径自相矛盾**。

审稿人明确：「腰围用于 LAP 比较，并不是主关联模型的必要变量。**这项差异可以直接修正，
继续仅把它列为局限性，说服力不足。**」

⇒ 处理顺序（不要只加局限）：
1. **三周期主关联统一**按"结局 + 指数 + 相应协变量完整"筛选（腰围不进主链）；
2. 腰围完整性**只用于共同判别样本**；
3. **重算受影响层的主模型与跨期比较**——实测 L 层从 2,056 → **2,092（236 例）**，
   M4 由 0.835 (0.698–0.998) P=0.048 → **0.826 (0.688–0.991) P=0.041**；
   **方向与显著性均不变**，但临界结果确实动了（审稿人预判正确：「不能预先假定恢复 36 人不会影响结果」）；
4. 原（更严）口径**保留作样本限制敏感性分析**，并在正文讲清
   **"关联样本 n / 判别样本 n" 的区分**（本例 2,092 vs 2,056），图注、表注同步。
- ✓ 判别分支常常**本来就不受影响**（腰围缺失者进不了以腰围为基础的比较指标），要顺手核对并写明。

### 2.9 \"无法验证 MAR，所以不做多重插补\" 不是理由（v18 新增）

审稿人原话：

> 「**\"无法验证 PIR 缺失符合 MAR，因此不进行多重插补\"不是充分的方法学理由。**
> **MAR 通常不能单凭观察数据证实**；**完整病例分析和选择加权也各自需要缺失机制或选择机制假设。**」

这是**方法学对称性**问题：你要求 MI 证明 MAR，但你自己用的完整病例法/选择加权同样依赖假设
（MCAR / MAR + 可忽略性）。用\"对方假设不可验证\"来解释自己的选择，逻辑上站不住。

⇒ 可复用写法（四段，直接把这段抄进方法与局限）：

1. **列出选择加权有效所需的假设**（本例 6 条）：MAR / 可忽略性、正值性（positivity）、
   选择模型正确设定、结局模型正确设定、无未测共同成因、SUTVA；并**明说 MAR 不可由观察数据证实**，
   完整病例法与选择加权**各有其假设**，\"不能验证 MAR\"**不构成偏好某一种的理由**。
2. **列出未进入选择模型的因素**（诚实清单）：本例含调脂/降压等药物使用、饮食与体力活动、
   睡眠与炎症、一般健康与医疗可及性、NHANES III 超声可及性、NHANES 无应答的非随机成分、
   非 PIR 的 SES 与实验室批次/季节。
3. **把\"结果基本不变\"限定适用域**：只能写成\"**在当前选择模型与当前目标人群限定下的稳健性证据**\"，
   不能写成一般性保证。
4. **做一次有明确假设的敏感性分析**（MI 不必作主分析），**多设定并列**报告。本例实测：

| 设定（M3 / M4 每 SD OR） | P | L | N3 |
|---|---|---|---|
| S0 主（目标 ∩ PIR 可得） | 1.645 / 1.335 | 1.415 / 0.833 | 1.999 / 1.244 |
| Sc 目标全域、模型不含 PIR | 1.641 / 1.338 | 1.425 / 0.832 | 1.994 / 1.242 |
| **S_MI** MAR 多重插补 m=20（Rubin 合并） | 1.643 / 1.344 | 1.421 / 0.831 | 2.001 / 1.252 |
| **S_MNAR** 缺失 PIR → 最低档 | 1.650 / 1.372 | 1.423 / 0.814 | 2.036 / 1.287 |
| **S_MNAR** 缺失 PIR → 最高档 | 1.635 / 1.320 | 1.424 / 0.826 | 1.988 / 1.206 |

- 五设定结论一致（M4 范围：P 1.320–1.372、L 0.814–0.833、N3 1.206–1.287），
  **且必须写明\"每种设定各有其假设，均不免除可忽略性假设\"**——否则等于宣称敏感性分析\"证明\"了 MAR。
- ⇒ 通用判据：**凡是用\"X 不可验证\"来正当化不做某个分析，先检查你自己用的方法是否依赖同级假设。**
  对称性是审稿人最先抓的逻辑漏洞。

## 四、把这条教训反过来用在写作上

**凡是在正文里引入一个新分析（选择加权、合并估计、尺度检验、精度量化），
下一轮审查几乎必然会问它"代表谁、怎么算、诊断如何、主要结果是多少"。**
所以新增分析时**一次把六要素写齐**，不要先报一个 ΔOR 再说"详见补充材料"——
那会被当作"只承诺不交付"。
