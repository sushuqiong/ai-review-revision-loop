# md → docx 手稿流水线：已验证的坑与铁律

来源：CHARLS+NHANES eGDR 稿件 v9→v16 连续 8 轮迭代（每轮都由外部 AI 审稿驱动）。以下每条都是实际踩过并修好的，不是推测。

## 1. md 是唯一真源；docx 只是产物
标准链路：`canonical.md` → `pandoc --standalone -o _raw.docx` → `/d/ProgramData/python.exe` 套三线表样式 → 版本化 docx（普通版 + ANONYMIZED 版各一份，均同步到项目根与投稿包）。

**绝不要**为了改稿而 `pandoc docx → gfm` 反向生成 md 再编辑。往返会：
- 把中括号转义成 `\[13\]`（导致后续所有字符串锚点失配，症状：批量 replace 大面积 MISS）
- 丢掉 YAML 元数据（`title:` 消失 → 匿名稿"标题不见了"，审稿人会直接点出）
- 把嵌入图变成 `<img src="media/rId24.png" ... />`（图片文件并未导出 → 重建 docx 时图全丢）
- 改变表格单元格空白与全/半角符号

只能把它当**灾难恢复**手段，且必须：① 先做 `s.replace("\\[","[").replace("\\]","]").replace("\\_","_")`；② 重新插入 YAML title；③ 用正则把 `<img ... alt="Figure N" />` 换回 `![Figure N](绝对路径/图.png)`；④ 重排补充材料顺序。

## 2. 禁止全局空白折叠
`re.sub(r"\s+", " ", s)` 会把整篇 md（含换行）压成一整行，摧毁所有 heading、表格与段落。一次误用直接废掉一份 4 万字符的原稿。
正确做法：只做**定向** `s.replace(old, new, 1)`；需要容错时用"逐行处理 + 只在行内折叠空格"。

## 3. 锚点漂移是常态，不是意外
多轮编辑后 `old_string` 失配必然发生。流程应为：
1. 先 `print(s.find(key))` 或打印 `s[i-90:i+180]` 的真实上下文；
2. 用真实文本做替换，别用记忆中的写法（英式拼写/弯引号/Ω 与 >= 差异都能让锚点失效）；
3. 每个补丁脚本**必须打印 MISS 清单**，逐条追到 0 才算完成（本会话多次靠 MISS 清单发现"补丁静默未生效"）。

## 4. 引用重排脚本会静默指向旧文件
`renumber_clean.py` 里写死的路径曾指向 `..._v9_raw.md`，于是每次运行都输出"total refs: 22"——**真实稿件的引用从未被重排**，而被误判为"新引用没被计入"。
排查口诀：**计数不变化 = 先怀疑文件路径/文件版本，再怀疑逻辑**。每次重排后核对 (a) 目标路径 (b) 数量变化 (c) `orphan refs` 与 `dangling cites` 均为空。

## 5. 非引用方括号会污染引文统计
基金号写成 `([2023]1)` 会被 token 扫描当成 `[2023]` 引用，产生"31–40 号引文缺口"之类的假报警。改为 `(2023-1)` 之类的无方括号写法。

## 6. 表与补充材料编号必须整体重排
插入新主表（如"窗口矩阵"升格为 Table 5）会打破既有编号：
- 全稿 `Table N`（N ≥ 新号）统一 +1 —— 注意**先插入再统一替换会把新表自己也算进去**（本会话出现过 `1,2,3,4,6,6` 两个 6），需在插入前记录旧标题位置，或替换后立刻 `re.findall(r"^## Table (\d+)\.", s, re.M)` 校验序列。
- 补充材料要按 `S1..Sn` 数值排序：`re.split(r"(?=\*\*Supplementary Table S\d+\.)", region)` 后按号排序重接；插入式添加常把 S15–S17 落到 S1 之前。
- 表格数、图数与正文引用数在交付前用脚本对账。

## 7. 图必须与最终数字同源，且每轮重跑
审稿意见原话："六张嵌入图片均与 v12 相同……仅更新图注会使图文冲突更明显"。
- 数据改动后**重跑全部图**并重生成 TIFF，覆盖 `图表/`、`投稿包/Figures/`、`Figures/TIFF_300dpi/`；
- 最稳的做法：亚组/森林类图**直接解析稿件里对应表格的数值**生成（保证"图表同源"零漂移）；
- 校准图直接读十分位 CSV（`cal_forward.csv` 等），不要在图里手敲数字。

## 8. 无视觉模型时的图形自查（代偿清单）
视觉端点不可用时（不要写进技能当结论），用代码级排查这三类最常见的学术图缺陷：
1. **文本越界被裁切**：`geom_text(x = 1.03)` 而 `limits = c(.4, 1.15)` → 长字符串必被截。办法：把标签列移到轴内独立位置并把上限留出 30–50% 空白（如 1.55）。
2. **标签压误差棒**：校准散点上的数值标签用 `vjust = -1.05` 统一上移，轴范围扩到 0–92%。
3. **流程图画布过窄**：排除人数标注外移时把 `limits` 放宽（如到 3.15）、画布加宽。
统一 `theme_classic(base_size = 12)`、轴字号 ≥10.5、图内文字 ≥2.9（≈8.5pt）、300 dpi 导出 PNG + LZW TIFF。
交付时**如实说明**"无法像素级检查，请用本地看图工具过一遍"，不要假装看过。

## 9. 交付前必跑的程序化自检
见 `scripts/manuscript_integrity_audit.py`。至少覆盖：摘要词数 vs 期刊上限（CD/BMC ≤350）、残留标记（旧版本句、修改说明句、"four methodological references"式版本注）、模型标签一致性（Base/M0/M1/M2，无 `M-1` 残留）、术语统一（同一指标只允许一种叫法）、表/补充材料编号与顺序、引用 0 孤儿 0 悬空、图文编号互指、括号配平、重复词、占位符清单。
