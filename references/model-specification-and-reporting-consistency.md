# 模型设定与报告的对应关系（specification ↔ reporting consistency）

来源：课题2 GLM7×胆石症 **v18 轮**，审稿人（GPT6）配发 `Hmisc` 官方文档，指出
「样条结点数、模型秩和非线性检验结果不一致（**可复算确认**）」。
这是**统计报告约定**类缺陷：**代码是对的，写出来的话是错的** —— 而审稿人只要算术就能抓。

通用规律：**只要稿子里同时出现「一个模型的自由度/秩/参数个数」和「一个检验的自由度」，
它们就必须能互相推出。** 推不出来 = 必被抓。

每条按「审稿人怎么抓 + 正确做法 + 实测数字」写。

---

## 一、样条结点数的两套惯例（最容易被抓的一处）

### 1.1 两套惯例说的是不同东西

| 惯例 | 入口 | 参数含义 | 3 个结点时 | 非线性 df |
|---|---|---|---|---|
| **R `splines::ns()`** | `ns(x, knots = q10, q50, q90)` | **内结点**（internal knots）；边界结点自动加 | 3 内结点 + 2 边界 = **5 总结点** | **3** |
| **Hmisc / rms** | `rcs(x, 3)` / `rcspline.eval(..., nk = 3)` | **总结点数** `nk` | 3 总结点 | `nk − 2` = **1** |

Hmisc 文档原文（`rcspline.eval`）：`nk` 默认 5；返回「`x`（若 `inclx=TRUE`）后接
**`nk − 2` 个非线性项**」。⇒ **Hmisc 的 `nk` 是总结点数**，非线性项 = `nk − 2`。

**实测（`ns` 行为）**：
```r
ncol(ns(x, knots = quantile(x, c(.1,.5,.9))))  # 4  ← 3 内结点 → 4 个基列
attr(ns(x, knots=...), "knots")                # 长度 3（内结点）
attr(ns(x, knots=...), "Boundary.knots")       # 长度 2（边界）
ncol(ns(x, df = 2))   # 2  ← 1 内结点 → 1 个非线性 df
ncol(ns(x, df = 3))   # 3  ← 2 内结点 → 2 个非线性 df
```

### 1.2 审稿人的算术（可复现的抓法）

GPT6 的原推理链，直接可复用为**自检模板**：

> 「按通常的总结点定义，**3 个结点产生 1 个线性项、1 个非线性项**，因此单个暴露的
> 非线性检验应有 **1 个分子自由度**。但第 3.4 节报告的 L 周期结果是 **3 个非线性自由度**。」
> 「模型秩也指向同一个疑点：M4 为 **17** 个参数，去掉线性年龄和 BMI，M3 通常应为 **15**；
> 将单个线性项替换为 3 结点 RCS，秩应**增加 1**，而稿件报告的样条模型秩为 **18**。」

⇒ **自检式**：`rank(样条模型) − rank(线性模型) = 样条基列数 − 1 = 非线性 df`。
本例实测：`18 − 15 = 3` → 基列 4 → **3 个内结点**（不是 3 个总结点）。
**三个数（内结点数、基列数、非线性 df、秩差）必须能互相推出，推不出就是报告错了。**

### 1.3 已经踩过的三种错法

1. **术语混淆**（本例）：代码用 `ns(knots = q10,q50,q90)`（**3 个内结点**），
   稿中写 “restricted cubic spline (**3 knots**)”——按 Hmisc 惯例读作 1 个非线性 df，
   与实测的 3 个 df 矛盾。
2. **把「内结点」写成「总结点」**（GPT6 原猜测之一）。
3. **真正的设定漂移**（本例同时存在，更隐蔽）：不同层的 P 值来自**不同规格** ——
   P 层 0.588/0.467 出自 `rcs(3 结点)` = **1 个非线性 df**，
   而 rank 18 出自 `ns(3 内结点)` = **3 个非线性 df**。
   ⇒ **一层一套规格 = 必被抓。** 必须**全稿统一到一个规格**，另一规格只作敏感性对照。

### 1.4 可直接改用的写法

> Non-linearity of the GLM7–dx association was examined in M3 with a **restricted cubic spline
> with 3 interior knots at the 10th, 50th and 90th percentiles (5 knots in total), giving
> 3 non-linear degrees of freedom**; the non-linear component was tested by a joint Wald F with
> the denominator degrees of freedom set to the design df.

配套补充表（一张，逐层给）：**实际内结点位置（3 个）| 边界结点（2 个）| 样条基列数 |
被检验的系数 | 线性模型 rank | 样条模型 rank | 分子 df | 默认分母 df | 显式分母 df | 对应 F、P**。
这张表本身就是「我们知道自己在报什么」的证据，能一次性关掉这类追问。

### 1.5 附带教训：「旧值不可复现」的判断要先穷尽口径

同一轮里我先断言某个旧 P 值「不可复现」，**这是错的** —— 我当时只在一种规格/一种样本口径下检索。
第二轮换规格与样本口径后**精确复现了它**（出自 `rcs` 1-df 规格 × 旧样本）。

⇒ **判据：宣布一个数字\"不可复现\"之前，必须把 (a) 规格、 (b) 样本口径、 (c) 尺度变换
三个维度都遍历过。** 否则你会在稿件里写下一个错误的\"该值不可复现\"声明——
那是把**自己的检索不彻底**写成了**数据的缺陷**，后果比原问题更严重。

## 二、跨期异质性：约束把要报告的差异抹平了

### 2.1 审稿人抓的是什么

GPT6 原话：

> 「目前有两套不同的比较…… 表2 的 M4：完整社会人口及生活方式协变量，再加年龄和 BMI；
> 表6 的年龄/BMI 调整模型：性别、种族、PIR，再加年龄和 BMI，**并约束其他协变量的系数跨周期相同**。
> 两者的 L 周期估计分别为 **0.826 和 1.014**，明显不是同一调整条件下的结果。」
> 「尤需注意：**表6 Panel C 的近期两周期比较，仅调整性别、种族、PIR，没有年龄和 BMI。
> 因此其中的 P=0.494 不能用来回答\"近期两个周期的 M4 条件关联是否不同\"**。」

两类问题：
1. **调整集不同** → 两个数字不是同一个量，却被放在一起解释；
2. **约束协变量效应跨期相等** → 这个约束会把**正是你要报告的期别差异**压平。

### 2.2 实测：约束掩盖了真实异质性（这条最值得记住）

本课题实测（三周期合并，完整 M4 调整集）：

| 设定 | 三周期 GLM7×period 交互 | 期特定 M4 OR（P / L / N3） |
|---|---|---|
| 约束协变量效应跨期相等 | F=3.775, **P=0.0277** | 1.129 / 0.991 / 1.337 ← **被拉平** |
| **放宽全部协变量×period** | F=7.620, **P=0.0015** | **1.326 / 0.825 / 1.244** ← **精确复现 Table 2** |

- **协变量×period 联合检验**：F=2.456 (df1=28, df2=42.0), **P=0.0041 → 约束被拒绝**。
- ⇒ **放宽后交互显著性由 0.028 强化到 0.0015**，且期特定估计与分层拟合完全一致。
  **原稿用约束模型做\"跨期异质性检验\"，结论方向没错，但把真实的期别差异抹掉了大半。**
- 通用判据：**当你报告\"各期估计方向不一致\"，检验它的模型就必须允许协变量效应随期变化。**
  用约束模型检验 = 在问一个不同的问题（\"在协变量效应相同的假设下是否还有差异\"）。

### 2.3 报告规范（避免摘要误导）

- **调整集不同的检验不能回答另一个调整集的问题**：Panel C（简化共同调整集，不含 age/BMI）
  只能叫「**simplified common adjustment set** 下的异质性分析」，**不能**用来回答 M4 差异。
  要回答 M4 差异，就**在同一暴露尺度、同一协变量定义、同一调整集**下做**期别系数差的直接检验**
  （本例：P vs L 在 M4 调整集下 F=1.388 (1, 23.0), **P=0.251**，与简化口径的 0.494 **含义不同**）。
- **摘要不得把两个不同起点的结论并列**：原稿把「M4 方向变化」与「显著跨周期异质性」紧挨着写，
  读者会以为后者验证了前者。⇒ **分别陈述**（三周期 M4 交互 P=0.0015，期特定 OR 1.33/0.83/1.24；
  P vs L 的 M4 差异 P=0.251 未达显著）。
- **同一数据两个差很多的 L 估计值，必须给成因分解**（本例：0.826 vs 1.014）：
  实测分解为 **①调整集影响小**（共同尺度 0.830 → 0.809）；
  **②主要来自估计策略**（该层单独拟合 vs 三周期合并 + 协变量效应跨期约束：0.830 → 1.020）。
  ⇒ 合并估计**借用了其他层的信息**，且该约束已被 P=0.0041 拒绝 —— 写清楚，否则读者无从调和。

## 三、可复用自检清单（每次报\"模型 + 检验\"前跑一遍）

```
[ ] 样条：内结点数 / 基列数 / 非线性 df / rank 差 —— 四个数互相推得出吗？
[ ] 术语：写的是「knots」还是「interior knots」？读者按惯例会读成几个 df？
[ ] 全稿：所有层的样条 P 是否来自同一规格？
[ ] 尺度：比较的 OR 是否在同一增量、同一口径样本上？
[ ] 调整集：用来回答问题的检验，其调整集与问题中的模型是否一致？
[ ] 约束：报告\"各期不一致\"时，检验模型是否允许协变量效应随期变化？
[ ] 数字声称：写\"不可复现\"前，规格 / 口径 / 尺度三维度都遍历过了吗？
```
