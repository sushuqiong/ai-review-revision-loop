# 公共组学资源核验清单（Public-Omics Resource Audits）

> 触发：用公共队列（GEO / TCGA-cBioPortal / CELLxGENE）搭证据包或数据资源论文，
> 或外部审稿人质疑"样本混用 / 分母不对 / 配对不当 / 跨平台不可比"时。
> 本轮（EGFR v11→v12）**每条都抓到真 bug**，且其中 2 条是审稿意见未列出的。

## 1. 队列 ≠ 患者（先算三类计数）
分别统计并报告：**检测记录数 / 唯一样本数 / 唯一患者数**；配对患者另计。
本轮实例：27 队列 = **2,754 检测记录、1,138 唯一患者、699 配对患者、12 平台**。
- 抽每队列的样本 ID 列表（GSM 等）做跨队列去重检查；用示例 ID 做冒烟测试不够，要全量。
- 报告时禁止写"N 个队列 = N 组患者"；不同数据层疾病名相同**不代表同一批患者**（不得包装成患者级多组学资源）。

## 2. 组织学必须按患者级字段核验（学名会骗人）
- 反例：cBioPortal `esca_tcga_gdc` 的样本级 `CANCER_TYPE_DETAILED` **全填 adenocarcinoma**（不可用）；
  **患者级 `DISEASE_TYPE`** 才可靠：96 鳞癌 / 89 腺癌。
- 处理：按患者级字段筛出目标组织学 → **重算该层全部下游**（表达、突变、CNA、生存）→ 记录排除数。
- 教训：混入错误组织学会**制造假结论**。本轮纯鳞癌重算后，原"EGFR 保护性 HR 0.56 / 扩增悖论"
  在单变量层**无任何 FDR<0.10**（原结论由混入的腺癌样本支撑）→ 主动撤回旧主张。
- 一致性：确认表达/突变/CNA/生存各层使用**同一**组织学范围。

## 3. 突变分母与"野生型"表述
- **禁止**用 CNA 样本数当突变分母（曾把 `n_sequenced` 写成 CNA 计数）。
  分母取 cBioPortal 的 **mutation-profiled 样本列表**（`<study>_sequenced`，可用 API
  `/sample-lists/{id}/sample-ids` 拉取）。
- 措辞：profiled 且无记录 → "**no mutation reported in the selected mutation data**"；
  profiled 名单之外 → **not assayed / unknown**。**不得**写成 "explicit wild type / 明确野生型**"**。
- 分母必须随表输出（本轮：LUAD 559、CRC 534、STAD 431、PAAD 173、HCC 366、ESCC 185→纯鳞癌 96）。
- 与原研究比例不一致时（如 KRAS 107/173 vs 原文 140/150）：**如实说明口径差异**（样本子集、
  突变调用流程），不要强行对齐，也不要声称"已核实"。

## 4. 单细胞：分组来自源 obs、配对必须尊重独立性
1. **分组定义**必须在源 h5ad 的 `obs` 里查（`Sample Type` / `disease` / `sample_category` /
   `control_vs_disease` / `group` …），**不要沿用缓存 CSV 的 group 列**；把原始标签与整理标签、
   映射规则分开保存。
2. 三类对照要分开编码：**健康供者 / 癌旁 / 肿瘤**；非病例-对照类别（如 `inutero`）剔除。
3. **独立性检查**（本轮抓到真错）：同一供者常同时贡献两个臂 → 逐细胞型统计
   跨臂供者重叠；规则：
   - 完整配对 ≥5 → **配对 signed-rank**（报对数）；
   - 两臂**供者互斥** → 可用非配对 MW（明确标注 donor-disjoint）；
   - 既重叠又不足 5 对 → **报"not testable"**，禁止"对数少就当独立"。
   本轮实例：240 个比较 → 12 配对 / 6 供者互斥 / 19 细胞身份对比 / **80 not testable**。
4. **标签一致性**：非肿瘤样本里出现 malignant 标签（本轮 358 个细胞）→ 标记（flag）而非改写，
   并在排除/标记日志里记录。
5. **整层排除也要记录理由**：某些数据集只有肿瘤、无对照臂（本轮 LUAD 117,266 细胞）→ 从
   差异资源中排除并写明原因。
6. 细胞身份对比（恶性 vs 正常上皮）与同细胞型疾病效应**分族校正**，不得混在同一 BH 家族。

## 5. 效应量分母必须一致（配对 + 非配对混池时）
- metafor：`SMD` 分母 = 合并 SD；`SMCRH` 分母 = sd1；**`SMDH` / `SMCRPH` 分母 = √[(sd1²+sd2²)/2]**。
  要把配对与非配对放在同一尺度，就用 **SMDH（非配对）+ SMCRPH（配对，实证 r）**。
- 必报**估计器敏感性**：REML/Knapp-Hartung（主）vs DerSimonian-Laird vs ad hoc KH（非收缩 SE）
  vs 仅非配对。本轮存活数 **17 / 74 / 6 / 3**——差异必须公开，而不是只报最好的那个。
- 配对口径修正后要**重跑所有受影响附加分析**（留一、评分一致性、ρ 敏感性等）。

## 6. 组成校正的诚实话术
- 报**基础模型 vs 调整模型（同样本）**的 β/SE/CI，外加 **|β_adj|/|β_base| 中位比值**（本轮 0.87），
  量化"衰减幅度"；**禁止**把"显著性消失"写成"组成解释/完全衰减"。
- xCell 是**富集分数**不是细胞比例；与其他方法的一致性只能称"方法一致性"，不能当比例准确性验证。

## 7. 基因覆盖与跨平台可比性
- 出**队列 × 模块 的覆盖表**（present/missing 基因逐条列出）；本轮 16/17 模块在至少一个队列不完整，
  最差 RET_ALK_NTRK 33%、RAS_MAPK 58% → 提供**共同基因集重打分**选项。
- 同名的模块在两平台纳入不同基因，生物学含义可能不同；**"统一效应量"不能解决覆盖差异**。
- 不要为了"看起来统一"把所有平台/组织/疾病拼成去批次大矩阵。
- 评分层不可混：bulk GSVA z ≠ member-mean z ≠ 单细胞 member-mean，必须分别标注。

## 8. 资源型论文的交付物（GPT6/编辑会逐项要）
资源包按 10 目录组织：注册表（accession/原文/下载日期/校验）· 样本注释（患者/样本/检测分别编号、
组织类型、病例-对照角色、配对、排除原因）· 表达与转换日志 · 模块定义+覆盖+样本级评分 ·
组成注释 · 单细胞（原始/整理标签、患者级汇总）· **完整估计层（含阴性/不可估结果）** ·
QC（覆盖、排除日志、版面检查、数值复现）· **可运行复用示例 ≥2 个** · 环境与运行顺序。
- 另附 `00_README.md`：**字段字典 + 连接键 + 评分层不可混 + 已知限制 + 许可**。
- 复用示例要**实跑并产出 expected_output/**（本轮示例 2 复现中位比值 0.872，与正文 0.87 一致）。
- 仓库：Scientific Data 强制 DOI 归档（首轮可用匿名下载链接，**第二轮起必须 depository**）；
  许可 CC0/CC-BY，**禁 -NC/-SA**；给用户写"点哪里"级上传指南（标题/描述/关键词/许可文本可照抄）。

## 9. 收工前一致性检查（脚本化，别手改）
- 正文/图表/README 的所有数字**从冻结表注入**，并写一个 `check_*.py`：核关键数字、
  摘要/标题字数上限、图表交叉引用、旧数字残留扫描（如 `retained 7`、`573 tumour`）、
  引文首现顺序与未引用条目。本轮 v12 检查 23/23 通过。
- 结论改变时，写**版本说明**（旧数字 → 新数字 + 依据表），并在仓库加 ERRATA 段落。
