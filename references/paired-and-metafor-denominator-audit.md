# 配对效应量 / Meta 分母 / 样本资格 审计清单

> 适用：病例-对照转录组图谱、meta 分析、外部队列验证类稿件的"外部 AI 审稿 → 重算"环节。
> 来源：一次连续 3 轮外部 AI 审查（v9/v10/v11），每轮都抓到**真实代码 bug**，教训是：
> **"看起来合理"的数字必须能被标准实现复现，否则默认是 bug。**

## 0. 一条铁律
**所有入稿数字必须由冻结结果表（`results/*.csv`）生成，并有一键核验脚本比对正文 ↔ 表。**
任何"手写数字/凭印象改数字"都会导致正文与图表不同步（本会话被抓 5 处：4.9 残留旧值、Methods 与 Results 样本量不一致、两种组成方法重叠数、单细胞命中数、结论句）。

## 1. 配对样本索引 bug（最隐蔽、最致命）
```r
# 错误：用"子集内的位置"去索引整条向量
yc <- y[match(cc, pid[iscase])]; yr <- y[match(cc, pid[!iscase])]      # ✗ 当病例不位于前 n 行时完全错
# 正确：先取子集值，再按患者 ID 匹配
yc <- y[iscase][match(cc, pid[iscase])]; yr <- y[!iscase][match(cc, pid[!iscase])]   # ✓
```
**症状指纹（用来快速判定）**：配对相关恒为 1；方差列全 NA；配合"先删 NA 再汇总"的脚本 → 整批配对队列被静默剔除。
**自检**：脚本必须打印 `paired rows estimable: k / k_total`；k 明显小于预期即 bug。
**若用了自助实现（dz×√(2(1−r))）也容易连带出错——直接换标准实现**（见 §2）。

## 2. metafor 效应量：分母必须一致（GPT6 级意见）
| measure | 标准化分母 |
|---|---|
| `SMD`(g) | 两组**合并 SD** |
| `SMDH`(g) | √[(sd1²+sd2²)/2]（异方差，Hedges 校正） |
| `SMCR` / `SMCRH` | **sd1**（原始分数标准化） |
| `SMCRP` / `SMCRPH` | √[(sd1²+sd2²)/2]（合并/平均方差，Hedges 校正） |

- **非配对用 `SMDH` + 配对用 `SMCRPH`** 才是同一分母、可直接合并；"都是标准化效应量"≠同一尺度。
- 配对需 `ri`：优先**逐队列×模块实证相关**，并跑 `ri=0.5/0.7` 固定值敏感性（结论若随 ri 变化必须如实写）。
- 汇总：主结果 **`rma.uni(method="REML", test="knha")`**；同时给 `method="DL"`、`test="adhoc"`（非收缩 KH）与"仅非配对队列"四种设置——小 k 下结果可能差 2–4 倍，这是**推断方法敏感性**，必须一起报告而不是挑一个。
- 每个状态报告 k、估、95%CI、p、BH-FDR、I²、τ²；k=1 不进 meta。
- 不要自写 `reml_tau()` 迭代（易出 NaN 且不可复现）；用 metafor 并记录 sessionInfo。

## 3. 分层纳入条件（一个筛选毁掉另一个分析）
- 症状：联合模型/组成校正的汇总数远小于预期，整癌种"消失"。
- 原因：先按 A 层（如统一效应量方差是否有限）删行，再用同一对象汇总 B 层（联合模型系数）。
- 正确：**每层独立纳入**，并显式分类状态：`robust / estimated(not significant) / estimated(not meeting rule) / not analysed`，报告四类计数。
- 集合关系不是包含关系（本会话：STAD meta 显著 0 个，组成稳健 9 个）——图 1 应画**并行证据层**，不要画成逐层筛选漏斗。

## 4. 样本资格与分母（外部队列 / 突变 / 驱动）
- **突变率分母**：必须取自"有突变数据"的样本列表（cBioPortal `<study>_sequenced`）；**不能**用 CNA 样本数或表达样本数（本会话 bug：`n_sequenced` 实际取了 CNA 计数）。
- **野生型定义**：仅"已 profiled 且无该基因突变记录"记为野生型；非 profiled 样本排除并**计数**（报告 `n_excluded_not_profiled`）。
- **外部队列组织类型**：按显式组织字段排除癌旁（如 GSE39582 `dataset:ch1` = Non Tumoral，17 例/3 事件）；同时核对患者重复。
- **分期字段解析**：先打印取值域再解析（数字 1–4 / 罗马数字 / 0 / N/A 混用很常见）；阶段 0 与 N/A 的处理要写明。
- 与原始文献口径不一致时（例：TCGA PDAC 原文 140/150 vs 本分析 profiled 107/173），**如实并列并归因于样本子集与调用流程**，不要强行对齐。

## 5. 幂等性与连接
- **禁止事后翻符号**（`d_adj <- -d_adj` 之类）：重复运行会再翻一次 → 改为在模型里显式设定参照水平 `factor(group, levels=c("Control","Case"))`。
- **按样本 ID 连接**（表达 × 组成分数 × 临床），不要依赖行序；连接后断言丢失率（例：`length(common) >= 0.9*ncol(expr)`）并打印。

## 6. 三项可复现性验证（每次改动效应量实现后必跑）
1. **手算 vs 标准包**：同一队列同一模块，手算 `(mean_case-mean_ctrl)/√((var_c+var_t)/2)` 与 `escalc()` 结果对照（量级一致即可，Hedges 校正会略差）。
2. **洗牌样本顺序**：随机打乱列顺序后按 ID 连接，`yi/vi/ri` 必须与原始完全一致（`all.equal`）。
3. **重复运行**：连跑两次结果完全一致（检查是否还有随机性/累积副作用）。

## 7. 报告写法
- 头条数字只给一个主设置，紧跟一行敏感性（"74 under DerSimonian-Laird; 6 with non-shrinking Knapp-Hartung; 3 unpaired-only"）。
- 失去显著性 ≠ 组成解释/无效应：写"未达预设稳健标准；不能区分系数缩小、标准误增大与共线性"。
- 外部未复现写"未复现（not replicated）"，不写"无效应"；给出 95%CI 与分期校正后结果。
- 修正历史（配对索引、纳入筛选、组织/分期、分母）写进 **ERRATA + code**，**不要**写成论文的主要方法学创新。
