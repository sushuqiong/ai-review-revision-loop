# 数据资源稿（Data Descriptor）的统计加固清单

来源：GPT6 对 v15 的意见第 1 条（「最实质的统计风险」）+ 本轮实际补强。凡是「多队列合并 + 派生分数」的资源稿都适用。

## 1. 效应量必须**完整定义**，否则审稿人一定打

写进正文（且与代码同向）：

```
SMDH   = J · (m_case − m_control) / sqrt((s_case² + s_control²)/2)     独立样本
SMCRPH = 同一分母，用于配对均值差，用组内相关 r                       配对队列
J      = 1 − 3/(4(n_case + n_control) − 2)                            小样本校正
v      = (n_case + n_control)/(n_case · n_control) + y²/(2(n_case + n_control))
```

两个坑：
1. **分母要命名**。`sqrt((s_case²+s_control²)/2)` 是均方根分母，**不是**经典 Hedges g 的样本量加权合并 SD；用 SMDH/SMCRPH 命名并说明为何选它。
2. **配对与非配对不能静默混池**（本轮 442 条 per-cohort 里 251 条是配对，占比过半＝实质而非学术问题）。必须同时给：联合估计 + **按设计分层的估计**（本轮 170 状态 → 165 联合 / 83 仅配对 / 64 仅非配对），并报告每队列贡献的 measure。

## 2. 方差不能假设，要**跑蒙特卡洛证明**

15 组（样本量 × 效应量）+ 每组 4000 次重复，比「解析方差/经验方差」与「95%CI 覆盖」并随包：
本轮结果 比值 0.92–1.03（中位 0.97）、覆盖 0.94–0.95 → 一段话把「你假设了方差」变成「你验证了方差」。

## 3. 五类敏感性，各自回答一个真问题

| 问题 | 分析 | 本轮结果 |
|---|---|---|
| 分母约定会不会改变结论 | 用经典约定（加权合并 SD；配对 d_z·√(2(1−r))）**重算整个估计层** | 163/165 同号（99%）、中位差 0.014、最大 0.49 |
| 某个噪声队列是否在驱动结果 | 对照最少队列的排除敏感性 | 去掉 5 对照队列后 HCC 全部 17 状态降为单队列、一律 not estimable → 如实写「最不稳健层」 |
| 配对相关 r 影响多大 | 主分析用估计 r；r=0.5/0.7 作敏感性；声明 r 的不确定性不传播 | 三个口径都随包 |
| 合并模型 | REML+HK 为主；DL、ad-hoc KH、仅非配对为备选 | 五套表 |
| 覆盖率 | 0.60/0.80/0.90 阈值重算显著性 | 13/13/12/6 |

## 4. 失败也要随包

`not_estimable_pairs.csv`（含原因：单队列/缺对照臂/零方差）；k=1 行必须标注 `pooled = "no (single cohort; not a pooled estimate)"` 且估计列置 `not applicable` —— 审稿人专门找「k=1 行混在合并表里」。

## 5. 跨队列一致性要「描述」不要「可重复」

- 给比例 + **Wilson 区间**，并声明是 pair-level 而非 cohort-level 率；
- 给 k 分布 + **k≥3 限制下的复核**；
- 命名为 **descriptive pair-level sign consistency**，绝不叫 reproducibility；
- 说明 k=2–3 时单一队列即可翻转（本轮 53/53 个不一致对全部由单一队列反调决定、无对使用超过 3 个队列）；
- 点名不一致集中在哪些情境/模块 + 一个实例（asthma 的 SRC_FAK 两正一负；CRC 的 ERBB_RECEPTORS 3 中 2 正）。

## 6. 独立复算要真独立

用**另一种语言/实现**（纯 Python 无项目依赖）重算三件事并报告差值：从均值/SD 重算一个效应量、REML+HK 合并一个状态、BH 校正一个家族。
实测：合并估计差 8e-17、BH 精确 0、从**四舍五入后的汇总**重算效应量差 ~1e-5（并解释这个量级来自随包值已舍入——解释容差本身就是严谨证据）。
**最大差 = 0 只说明输入相同、算术确定**，必须如实说明，不能当作独立验证。

## 7. 单细胞层（若有）

- **供者级效应量 + bootstrap CI 为主结果**（重抽供者而非细胞）；P/FDR 列在文件与正文都标 `exploratory`；
- 供者丰度阈值网格：无下限 / ≥10 / ≥20 / ≥50（本轮 240/200/184/160 比较，显著数 37/41/32/30）——注意**可检验数非单调**（阈值更严可使臂变成供者不交叠，从而合法用非配对检验），必须在正文解释；
- 多重校正三口径（比较类型家族＝主、细胞类型家族、全局）同表并列：本轮显著数 30–53，**这个跨度本身就是结论**，不能把某个数字当发现；
- 随包每供者细胞数分布（<10/<20/<50 的单位数），供者小样本如实披露。
