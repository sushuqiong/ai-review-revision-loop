# 效应量定义与多重校正的"加固四步"（Effect-size & multiplicity hardening）

**触发**：审稿人质疑"你的效应量分母/方差公式是否标准""配对与非配对是否混用""FDR 显著数能否当结论"。
这类质疑**不能只改措辞**，必须补齐可复算的证据，否则下一轮审查必然再次命中。

## 第一步：写出公式并给分母命名
- 正文必须显式写出公式与符号定义，并**命名分母**。若用的不是经典 Hedges g 的样本量加权合并 SD，
  就单独起名并说明差异，不要把非标准量直接叫 "Hedges g"。
- 工作示例（RMS 分母）：
  `SMDH = J (m_case − m_control) / sqrt((s_case² + s_control²)/2)`，
  `J = 1 − 3/(4(n_case + n_control) − 2)`；配对用同一分母作用于配对均值差并引入组内相关 r
  （主分析用数据估计的 r，另附 r = 0.5 / 0.7 两个敏感性）。
- 同时说明**为什么可以有多个度量并存**：设计不同 → estimand 不同 → 必须让读者看出每个状态由哪些度量支撑
  （每个状态列出各队列所用 measure）。

## 第二步：用蒙特卡洛验证方差公式（而非只声称）
- 配方：样本量网格 × 效应量网格（例如 (8,8),(12,12),(20,20),(40,40),(60,30) × δ = 0,0.3,0.8），
  每组 ≥4,000 次重复；对每次重复按**与主分析同一公式**计算效应量；
  报告 `解析方差 / 经验方差` 的比值区间与解析 95%CI 的实际覆盖率。
- 通过标准（可直接写进正文）：比值落在 0.9–1.05、覆盖率 ≈0.94–0.95。
  实测（EGFR 资源 v16，15 组设置）：比值 **0.92–1.03（中位 0.97）**，覆盖率 **0.94–0.95** → 公式可用。
- 产物：`08_qc/qc_smdh_variance_monte_carlo.csv`（n_case,n_control,true_delta,mean_estimate,
  empirical_variance,analytic_variance,ratio,coverage）+ 补充表。

## 第三步：全套重算的"经典约定"敏感性（最强回应）
- 用标准约定**重算整个估计层**，逐状态与主口径比对：
  - 非配对 → Hedges g（样本量加权合并 SD）；
  - 配对 → `d_z * sqrt(2(1−r))`（把组内标准化均值变化换算到同一尺度）。
- 必须报告三件事：**同号比例**、**中位绝对差**、**最大绝对差**（标准化单位）。
  实测（165 个状态）：**163/165 同号（99%）、中位 |Δ| 0.014、最大 0.49** → "结论不依赖分母约定"。
- 产物：`07_estimates/meta_classic_denominator_sensitivity.csv`。

## 第四步：停止"静默混合设计"，改为分层报告
- 只把分层当附属分析是不够的：**按设计分层（paired-only / unpaired-only）与联合估计并列**，
  并在正文给出分层状态数（例：170 状态 → 165 联合 / **83 仅配对** / **64 仅非配对**）。
- 配对判定与阈值要写明（例：≥4 例患者同时贡献两种组织才作配对；该阈值本身要说明依据）。
- 产物：`07_estimates/meta_by_design_stratum.csv`（含 cohort 列表、k、est、se、p、CI）。

## 方向一致性（sign concordance）的表述纪律
- 百分比必须命名为 **descriptive pair-level sign consistency**，并同时给出：
  Wilson 95%CI（逐对、非独立，须声明）、`k ≥ 3` 限制下的同值、k 分布、以及**明确否认**外推
  （"不是新队列的预期一致率"）。
- 单一队列即可翻转方向时必须点名（例：每个不一致对都由单一队列反调、无对使用 >3 队列）。
- 排除敏感性：对最弱队列（对照样本最少者）单列敏感性文件；
  若移除后状态降为单队列 → **如实写"标记为 not estimable，不合并"**，并把该疾病层标为最不稳健部分
  （实测：HCC 17/17 状态下该队列为唯一伙伴，移除后全部不可估计）。

## 多重校正（单细胞/多比较层）
- 显式定义 **primary family**，其余（cell-type family、global BH）列为补充；
- 报告**阈值/家族梯度表**，并注明数字随家族规模变化；
- 任何 FDR 显著数一律标注 **exploratory**，并写明"不作为生物学发现"；
- 主结果改为**供者级效应量 + bootstrap 95%CI**；另出每供者细胞数分布（<10/<20/<50）。

## 常见退修措辞 → 必须交付的产物（对照表）
| 审稿人说法 | 必须新增的产物 |
