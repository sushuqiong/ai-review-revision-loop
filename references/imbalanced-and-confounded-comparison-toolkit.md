# 组间不平衡 / 混杂被审稿人质疑时的"硬化"工具箱

> 触发：审稿人/编辑说「两组样本数悬殊（6 vs 122），显著性可能失真」，或
> 「你的指标含年龄、高暴露组老了 23 岁」。这类质疑**不能靠辩解**，只能靠**现算的真实数字**回应。
> 原则：先跑通原文所有数字（见 references/revision-reproduction-first.md），再补这些分析。

---

## 一、极端不平衡的两组比较（如 6 vs 122）

### 先做一件反直觉但必须先做的事：给 P 值做"经验校准"
在上位机**全体探针**上跑同一个检验，算出背景"显著率"。
本会话（GSE83148，54,675 探针，Wilcoxon，2 样本秩和用**秩和+并列校正的向量化 z 统计**算，比 `apply(wilcox.test)` 快两个数量级）：

| 阈值 | 观察到的探针数 | 均匀零假设期望 | 经验 FDR |
|---|---|---|---|
| p ≤ 0.01 | 25,715 | 546.8 | **0.021** |
| p ≤ 0.001 | 14,925 | 54.7 | 0.004 |
| p ≤ 0.0001 | 4,463 | 5.5 | 0.001 |

**结论：该设计下 61.8% 的探针 p<0.05、47.0% 的探针 p<0.01**——因为"正常肝"与"CHB 肝"整体转录组就不同。
所以在这类设计里 **P 值本身不携带信息**，必须在正文里明说，并把结论落到与组大小无关的量上。

### 回应时递交的五件套（缺一不可）
1. **非参数检验**：Wilcoxon 秩和——不假设正态、不假设等组大小或等方差（在 122:6 下是唯一合适的默认）。
2. **FDR**：BH 校正后的 q 值，而不是原始 P。
3. **与组大小无关的效应量**：log2FC、Cohen's d、**AUC**（= P(CHB 值 > 对照值)，并列计 0.5）。
   本会话实测：d = 0.80–2.47，AUC = 0.71–0.99。
4. **保持原分配的重抽样**：10,000 次置换（每次从合并池抽 122+6，**保留 122:6 结构**）+ **留一法 jackknife**
   （逐一去掉每个对照做 6 次，报告最大 P）——直接回答"是不是某一例对照在驱动结果"。
5. **集合水平（competitive）检验**：把 9 个 hub 基因作为一个集合，与其余全部探针比。
   本会话：集合平均 log2FC 1.95 vs 全集 0.25；set-vs-rest Wilcoxon P = 2.9e-07；置换 P = 1e-04。
   **优势：集合内部自带对照，不受组间不平衡影响**，是这类设计里最有说服力的单条证据。

### 必须同时做的一件事：如实降级不符合的口径
本会话原文写 "all nine genes significant (all P<0.05)"，实算 **FAT1 p = 0.088（不显著）**。
- 处理：正文改为"**eight of nine** significant after FDR"，并写明 FAT1 方向一致（log2FC +1.03、d = 0.80）但未达显著，原因是只有 6 例对照。
- **不要**只挑显著报告。审稿人质疑的正是"显著性是否失真"，主动交出个案失败**恰好证明**你理解了该设计的局限。
- 另注意：把 GEO series matrix 里**已经标准化过的** log2 值再做一次 quantile normalization 会改变结论
  （本会话 FAT1 由 p=0.088 变成 p=0.164）。Methods 要写明"直接用 GEO 提供的标准化值（等同 GEO2R），不再重复标准化"。

## 二、"暴露指标含年龄／组间年龄差很大"的回应套路

本会话主编原话：*"FIB-4 incorporates age. The higher fibrosis group is 23 years older."*

**四层递进**（按证据强度排序，全部实算）：
1. **分层内看**：按年龄十年分层，逐层比较暴露组 vs 对照组的结局均值。
   本会话每一层内高 FIB-4 组 AIP 都更低 → 不是年龄假象。（这一条**最直观**，做成一排柱状图）
2. **弹性调整**：把年龄放进 **自然立方样条 `ns(age, df=4)`** 重跑主模型（β 由 −0.133 → −0.118）。
3. **窄年龄带限制**：40–59 / 50–69 / 60–79 各自重跑（β = −0.195 / −0.158 / −0.115，全 P<0.001）。
4. **把年龄项从公式里删掉**——**最有力的一条**。FIB-4 = (Age×AST)/(PLT×√ALT)，去掉年龄即
   `FIB-4 core = AST/(PLT×√ALT)`；它仍与结局独立相关（每 log 单位 β = −0.131，95%CI −0.166~−0.096，P=1.0e-05）。
   **同一条公式只删掉被质疑的那一项**，比换用别的指标（如 APRI）干净得多。

再加一条"方向性"论证：本会话全调整后**年龄本身与 AIP 无关**（β=0.0002，P=0.67），
即年龄差只会把结果推向零假设而**不是**制造出关联——写进正文，逻辑上把质疑关掉。

> 取舍记录：本会话另跑了不含年龄的 APRI，结果只是方向一致而不显著（β=−0.055，P=0.075）。
> 因为主编问的是"FIB-4 含年龄"，FIB-4 core 是**同一公式的直接答复**，故以它为主证据、APRI 未写入正文。
> 但**必须把这个取舍告诉用户**（"我跑了 APRI 但没写进去，你要全摊开我就加"）——不告知就是选择性报告。

## 三、阈值/参数选择被质疑（如 STRING 0.4 vs 0.7）

**先分清"结论依赖什么"，再补稳健性**。本会话审稿人问"为什么用 0.4 不用 0.7"：
- 核心答复：**hub 基因是机器学习从表达矩阵筛的（RF 的 Gini 降幅 + SVM-RFE），与网络拓扑/阈值无关**；
  网络只用于可视化与模块描述。所以"九个 hub 基因会不会变"在逻辑上不成立。
- 再补实测：0.4 时 92 节点/340 边 → 0.7 时 55 节点/124 边；
  **两个模块与核心边完全保留且分数不变**（CXCL9–CXCL11 0.999、CXCL9–CXCR4 0.994、CXCL11–CXCR4 0.994、COL1A2–ITGB8 0.723）。
- 说明取舍理由（0.4 是 STRING 对小规模探索性网络的推荐默认值），并**两个阈值都呈现**（新增补充图 + 补充表），
  让读者自己判断——比只辩解"0.4 是对的"强得多。
- STRING 网络可直接用 REST 拉：`POST https://string-db.org/api/tsv/network`
  参数 `identifiers`（**用 `%0d` 连接基因名**）、`species=9606`、`required_score=400|700`。

## 四、这套分析的通用交付形态
- 每一条质疑 → **一张新增补充图 + 一张新增补充表**（本会话：S6 验证统计 / S7 网络阈值 / S8 年龄与 VCTE）。
- 图注里写清"为什么这样算"（例如"该设计下 61.8% 探针 p<0.05，故以效应量与 FDR 为主"），
  这样即使审稿人只看图也能读到你的统计判断。
- 逐条回复信里把**不利结果也列出**（crude 模型方向相反、FAT1 不显著、样本量仅 47.5% 有 VCTE）——
  审稿人质疑什么，就把那件事的完整图景交出去。
