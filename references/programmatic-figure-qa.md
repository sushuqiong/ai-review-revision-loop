# 程序化图件审查（视觉模型不可用时的六项检查）

> **触发**：任何"图已画好，检查一下"的时刻。本用户会直接反问「你不是可以用 OCR 或者其它工具审查吗？」——
> **禁止**回答"我没有视觉能力，只能靠人眼"。先跑完下面六项，再如实说明机器判据与人工审美判断的边界。
> 可执行实现：`scripts/figure_qa_pixel.py <fig_dir>`（本技能 scripts/ 下）。

## 六项检查与判据

| # | 检查 | 方法 | 通过判据 | 实测教训 |
|---|---|---|---|---|
| 1 | 页幅/分辨率 | 读 PNG IHDR + pHYs | 宽 ≤17.0 cm（双栏上限 17.2）、高 ≤24 cm、300 dpi | 曾出现 26.4 cm（超 24）与 31 cm 图；拆面板或压高度才能回到合规 |
| 2 | 边缘裁切 | OCR 词框触边 **且边缘条带内确有墨迹** | 0 | 只看"框触边"会误报；必须判边缘 40 px 内墨迹占比 >0.5% |
| 3 | 同行文字碰撞 | 两词框同线且水平区间相交 → **裁交集矩形数墨迹** | 0 真碰撞 | 交集空白(<2% 墨迹) = 假阳性；OCR 会把数字拆段（0.94→"0.9"+"4"）、把破折号拆成独立记号，需按"相邻 + 合并后是数字"排除 |
| 4 | 标签完整性 | OCR 词表比对期望集合 | 面板字母(A–D)、全部情境名、模块短名齐全 | 出图后必查：少一个字就是排版丢了元素 |
| 5 | 打印尺寸可读性 | **缩到 50% 再 OCR**，比对词数保留率 | ≥0.6（实测 0.6 = 边缘；提到 0.83 才放心）| 这一项才真正暴露"字太小"；仅看 100% 图会误判为合格 |
| 6 | 图例/总标题条带 + 边距 + 对比度 | 顶/底 3.5% 条带内列墨迹覆盖率；最外墨迹 bbox 求边距；词框内 5%/95% 分位亮度比 | 条带覆盖 <0.55（>0.55 视为图例/总标题条带，本用户禁用）；边距 >5 px；对比度 >3 | **对比度告警几乎全是单字符 OCR 碎片**（'5' '+' 'a' '&' '-'）→ 逐条打印词内容再判，别把碎片当结论 |

## 排版缺陷 → 修法对照（本轮真实修复）

| 症状 | 根因 | 修法 |
|---|---|---|
| 标题被右缘截断（OCR 读到 "lowest"/"non-sig"/"xCell)"/"scorabl" 的残段）| ggplot 标题单行超宽 | 加 `wrap_title()`（`strwrap(s, width=38)` 后折行）**并缩短标题**；`plot.margin=margin(5,14,5,5)` |
| 长标签贴边/与刻度互压 | 标签写在图内 `geom_text(hjust=...)` | 把长描述**移进 y 轴标签**（如 "CRC: tumour vs non-tumour (29 donors)"），图内只留短标签 |
| 165 个细标签堆叠（Fig3A）| 直接把每对都画成带全名的因子 | 面板改为"按组分布（散点+中位横杠）"，**明细移入补充表/数据仓库** |
| 分面横轴标签挤成一片 | 3 个分面并排 + 45° 旋转 | 分面**纵向堆叠**（每面整幅宽）+ 标签**改水平**（10 类在 17 cm 内放得下）；旋转标签的 OCR 框天然互压，会污染碰撞检测 |
| 模块/基因名过长导致右缘占位 | 全名入图 | 图内用**短名**（去 `_AXIS`/`_LIGANDS` 等后缀），全名映射写进**图例文件** |
| 面板众多导致字小 | 5 面板压进 22 cm | **拆图**（Fig2 A–C 与新增 Fig4 D–E 分开），字号提升到 ≥8.3 pt（约 3.0–3.2 in ggplot units） |
| 数值标签对比度低 | 灰色文字压彩色柱/散点 | 标注色改近黑 `#1A1A1A`；柱色避免浅灰配灰字 |

## 交付前的自检顺序（建议固化）

1. 从**冻结表**取数（不许手抄、不许估计；不可估计处标 `n.e.`）
2. 重画 → 跑六项检查（脚本）→ 若任何一项 FAIL，回到上表找修法 → 重跑，直到 PASS
3. 图例单独成 `.docx`（图内不放图例、不放总标题）；误差/中位线等统计处理**必须写进图注**
4. 四图全部嵌入正文 docx 且**图号顺序与图注一致**（曾出现"正文提 Figure 4、docx 只嵌 1–3、图注排在 Figure 3 之前"三连错）
5. PDF 版本若要投稿排版，优先用 `cairo_pdf`（R 已带 cairo 时）以**内嵌字体**；PNG 为主交付

## 必须写进报告的边界声明

- 机器检查覆盖：几何（裁切/碰撞/页幅）、文字层（标签完整性/可读性/条带/边距/对比度）。
- 机器检查**不覆盖**：配色审美、面板视觉平衡、语义是否误导。
- 因此结论表述为"程序化审查 PASS（0 裁切 / 0 真碰撞 / ≤17.0×24 cm / 标签齐全 / 50% 缩放保留率 x）"，
  并请用户**目检一次**做最终审美确认——不要写成"图完全没问题"。
